Environment issue encountered and resolution: `pip install -r requirements.txt` initially replaced the already-installed CUDA-enabled torch (2.14.0+cu130) with the CPU-only PyPI build, because silero-vad's dependency on torchaudio<2.10 forced a torch downgrade and pip's default index has no CUDA wheels. This is the exact trap SignSetu.docx warns about under "Note on torch." Fixed by reinstalling torch==2.9.1+cu128 and torchaudio==2.9.1+cu128 from https://download.pytorch.org/whl/cu128, matching the RTX 3050's driver (CUDA 13.1, backward-compatible with cu128 wheels). Also removed a stale, unrelated torchvision 0.29.0+cu130 install that was left over from before this session and was not part of any spec, since it created a version conflict against the new torch build and is never referenced by the pipeline.
